# ARS Digital Studio

Source for the ARS Digital Studio website: resume and portfolio services for students, AI automation for small businesses, and free student resources.

## Pages

| Page | What it is |
|---|---|
| `index.html` | Main storefront |
| `career-services.html` | Student resume & portfolio services |
| `toolkit.html` | Free BSCS student toolkit |
| `ars_club.html` | ARS Dev Club (applied AI & automation) |
| `free_sample.html`, `Free_Sample_*.html` | Free samples of the guides |
| `oop_sheet.html` | OOP exam & viva survival guide |

Built with plain HTML, CSS and Tailwind. Contact via the WhatsApp button on the site.
