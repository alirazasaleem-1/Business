1 The 4 Pillars in Plain English

Pillar Intuitive Concept Viva One-Liner
Encapsulation Keep variables private; only modify via getters/setters. Protects data from outside damage. "Binding data with methods and restricting direct access."
Abstraction Like a TV remote: push buttons to use it without worrying about circuit voltage inside. "Hiding internal implementation details using abstract classes/interfaces."
Inheritance Write common logic in a parent class; derived child classes reuse it (Car inherits Vehicle). "Deriving a child class from a parent class for code reuse."
Polymorphism Same function name draw(), but Circle draws a circle and Square draws a square. "Same function executes different behavior based on object context."

2 Compile-Time vs Runtime Polymorphism

Compile-Time (Early Binding)

Function Overloading & Operator Overloading.

The compiler decides exact function address before runtime. Faster, but rigid.

Runtime (Late Binding)

Function Overriding using virtual keyword.

Resolved dynamically at execution using a Virtual Table (VTable).

#include <iostream>
using namespace std;

class Base {
public:
    virtual void show() { cout << "Base Show\n"; }
    virtual ~Base() {} // Always make base destructors virtual!
};

class Derived : public Base {
public:
    void show() override { cout << "Derived Show\n"; }
};

int main() {
    Base* ptr = new Derived();
    ptr->show(); // Output: "Derived Show" (Runtime resolution)
    delete ptr;
    return 0;
}

3 Shallow Copy vs Deep Copy (Exam & Viva Trap)

Default copy constructors perform a shallow copy: pointer addresses are duplicated directly, meaning two objects reference the exact same heap memory block.

⚠️ The Double Free Trap: When both objects go out of scope, both call delete on the identical heap address, crashing the program. 
// CORRECT DEEP COPY IMPLEMENTATION:
class Student {
    int* id;
public:
    Student(int val) { id = new int(val); }

    // Deep copy constructor: Allocates fresh heap memory
    Student(const Student& other) {
        id = new int(*other.id); 
    }

    ~Student() { delete id; }
};

4 Top 10 Lab Viva Questions & Fast Answers

1. Can constructors be virtual?

No. Virtual dispatch requires a VTable pointer (vptr), which doesn't exist until the constructor creates the object.

2. Can destructors be virtual?

Yes, and base class destructors must be virtual to avoid memory leaks when deleting derived objects via base pointers.

3. What is a pure virtual function?

A function declared with = 0; with no body in the base class. It makes the class abstract.

4. Can you instantiate an abstract class?

No. You can only create pointers and references to it, not standalone objects.

5. What is the diamond problem?

Multiple inheritance duplicate ambiguity when two parent classes inherit from the same grandparent. Resolved with virtual inheritance.

6. Does `friend` function violate encapsulation?

Yes, technically, because it bypasses class privacy to access private/protected members.

7. What is the `this` pointer?

An implicit constant pointer holding the memory address of the current calling object.

8. Difference between Struct and Class in C++?

Only default access: struct is public by default; class is private by default.

9. What is object slicing?

When a derived object is assigned by value to a base object, derived-specific members are sliced away.

10. Can you overload based on return type alone?

No. The compiler requires different parameter types, numbers, or ordering.
