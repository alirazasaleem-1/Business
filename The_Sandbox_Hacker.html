Chapter 01

Why You Need a Cyber Lab

If you want to learn how hackers break into systems, you can't just read about it—you have to practice. But practicing on your own home network or public websites is incredibly dangerous (and illegal).

That is where a Cyber Lab comes in.

A cyber lab (or sandbox) is a simulated, isolated environment running entirely within your current computer. If you accidentally download malware or break a system in your lab, it cannot escape and harm your real computer. You just click "Reset" and start over.

Chapter 02

Installing VirtualBox

To build a lab, we need a Hypervisor. This is software that lets you run multiple "virtual computers" (Virtual Machines or VMs) inside your main computer.

We will use Oracle VM VirtualBox because it is powerful and 100% free.

Step-by-Step Installation:

  1. Go to virtualbox.org/wiki/Downloads.
  2. Click on "Windows hosts" (or macOS/Linux depending on your system).
  3. Run the installer and click "Next" through the default options.
  4. Once installed, open VirtualBox. You are now ready to add virtual machines!
You may need to enable Hardware Virtualization (VT-x / AMD-V) in your computer's BIOS settings if VirtualBox gives you an error when starting a machine.
Chapter 03

Setting Up Kali Linux

Kali Linux is the Swiss Army knife of cybersecurity. It comes pre-installed with hundreds of hacking tools.

Downloading Kali:

  1. Go to kali.org/get-kali/.
  2. Click on "Virtual Machines" (do NOT download the Installer Images).
  3. Download the VirtualBox 64-bit pre-built image.

Importing into VirtualBox:

Instead of installing Kali from scratch, the file you downloaded is a pre-configured machine.

  1. Extract the downloaded .7z file using 7-Zip or WinRAR.
  2. Double-click the blue .vbox file inside the extracted folder.
  3. VirtualBox will open automatically. Click Start to boot your new hacker machine!

Default Login: Username: kali | Password: kali

Chapter 04

Mastering the Terminal

In Kali, you won't use the mouse much. The real power is in the terminal. Open the terminal (black box icon at the top left) and try these commands:

# Find out where you are in the system
pwd

# List files in the current directory
ls -la

# See your network IP address
ip a

# Update your system (requires your 'kali' password)
sudo apt update && sudo apt upgrade -y
Use the Tab key to auto-complete file names and commands! It saves hours of typing.
Chapter 05

Your First Network Scan

Now that your lab is ready, let's use Nmap (Network Mapper). It is the most famous tool for discovering open ports and vulnerabilities on a network.

We will scan scanme.nmap.org — a server set up specifically for beginners to practice scanning legally.

# Basic scan to see open ports
nmap scanme.nmap.org

# Advanced scan to detect operating system and software versions
sudo nmap -sS -sV -O scanme.nmap.org

When you press enter, Nmap sends packets to the server and analyzes the responses. It will show you exactly what services (like HTTP, SSH) are running on that server.

Only scan networks and servers you have explicit permission to test. Unauthorized scanning can lead to severe legal consequences. Always practice safely within your virtual lab.
