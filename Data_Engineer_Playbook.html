Chapter 01

What is Data Engineering?

Before data scientists can train AI models or analysts can build beautiful dashboards, someone has to collect, clean, and store the data. That person is the Data Engineer.

If data is water, data engineers build the pipes, reservoirs, and filtration systems.

In this guide, you will learn the core concept of data engineering: ETL.

  • Extract: Pull data from an API, website, or CSV.
  • Transform: Clean the data, remove errors, and format it.
  • Load: Save it securely into a Database (like PostgreSQL).
Chapter 02

Setting Up Your Tools

We will use Python to write our scripts and SQLite (a lightweight built-in database) to store our data, so you don't have to install heavy database servers yet.

Required Python Libraries

Open your terminal and install Pandas (the ultimate data manipulation library):

pip install pandas requests
Pandas is the industry standard for transforming data in Python. It allows you to treat data like a highly-powered Excel spreadsheet in code.
Chapter 03

Your First ETL Script

Let's build a script that Extracts dummy user data from a free API, Transforms it to only keep what we need, and Loads it into a database.

import requests
import pandas as pd
import sqlite3

# 1. EXTRACT
print("Extracting data...")
response = requests.get("https://jsonplaceholder.typicode.com/users")
data = response.json()

# 2. TRANSFORM
print("Transforming data...")
df = pd.DataFrame(data)
# Keep only specific columns
df = df[['id', 'name', 'email', 'phone']]
# Clean phone numbers (remove extensions)
df['phone'] = df['phone'].str.split('x').str[0].str.strip()
# Convert names to uppercase
df['name'] = df['name'].str.upper()

# 3. LOAD
print("Loading into Database...")
conn = sqlite3.connect("users_db.sqlite")
# Save dataframe to a SQL table called 'users'
df.to_sql("users", conn, if_exists="replace", index=False)
conn.close()

print("✅ ETL Pipeline Completed Successfully!")

Run this script, and it will instantly create a users_db.sqlite database file on your computer containing the cleaned data!

Chapter 04

Querying Your Database

Now that your data is loaded, let's write a quick script to read it back using SQL.

import sqlite3
import pandas as pd

conn = sqlite3.connect("users_db.sqlite")

# Run a SQL Query
query = "SELECT name, email FROM users LIMIT 3"
result_df = pd.read_sql(query, conn)

print(result_df)
conn.close()
In the real world, you would connect to a cloud database like Snowflake, BigQuery, or Amazon Redshift. The Python code is almost exactly the same!

Next Steps

Congratulations! You just built a functional ETL pipeline.

  • Advanced SQL: Learn Joins, Window Functions, and CTEs.
